# AIMA

**Artificial Intelligence: A Minded Architecture**

An open-source framework for building autonomous cognitive agents using a neuroscience-inspired five-brain architecture.

## Five Brains

| Brain | Biological Analog | Role |
|-------|------------------|------|
| **Limbic** | Paleomammalian cortex | Human-facing interface (bidirectional) |
| **Cortex** | Neocortex | Internal reasoning engine |
| **Brainstem** | Reptilian complex | System-facing interface (bidirectional) |
| **Amygdala** | Amygdala | Pre-execution risk interrupt |
| **DMN** | Default Mode Network | Introspection, error correction, memory management |
