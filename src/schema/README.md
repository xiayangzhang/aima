# src/schema

Drizzle ORM table definitions. Maps directly to PostgreSQL tables. Do not write business logic here.

## Tables

| File | Table | Description |
|------|-------|-------------|
| `threads.ts` | `threads` | One row per cognitive thread (inbound event → terminal state) |
| `slots.ts` | `slots` | One row per brain per thread; holds brain input/output as JSONB |
| `memories.ts` | `memories` | All memory types (semantic/episodic/procedural/working/implicit) |
| `pending.ts` | `pending_observations` | Scheduled DMN work items and DEFER recovery records |

## Conventions

- Primary key: `uuid` generated by `gen_random_uuid()`
- Timestamps: `created_at` on all tables; `updated_at` on mutable tables (app-layer updated, no triggers)
- Soft deletes: `t_invalid timestamptz` (supersession) and `forgotten boolean` (expiry) on `memories`
- JSONB: `input`, `output`, `usage_outcomes` on slots/memories
- pgvector: `embedding vector(1536)` on `memories` for semantic search

## Usage

Import the barrel:

```typescript
import * as schema from './schema/index'
// or specific tables:
import { threads, slots, memories, pendingObservations } from './schema/index'
```

## Migrations

Generated by `drizzle-kit generate`, applied by `drizzle-kit migrate`. Never edit files in `drizzle/migrations/` by hand. Schema changes go in `src/schema/`, then regenerate.
